# LifeVax AI

AI-assisted Adult Immunization Gap Assessment — Ideathon prototype.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deployment

This app is designed for deployment on Streamlit Community Cloud.

Configure the Gemini API key through Streamlit Secrets instead of committing it to GitHub.

## Important

This is an ideathon prototype. The embedded vaccine rules are demonstration rules, not clinical recommendations. Before real-world use, replace them with clinician-reviewed, versioned Indian adult-immunization guidelines.
